# Zimbra Mail Trace

Веб-сервис для восстановления цепочки прохождения писем по журналам Postfix/Zimbra.

## Быстрый запуск

1. Скопируйте `.env.example` в `.env` и замените пароль PostgreSQL.
2. Запустите `docker compose -f docker-compose.yml up -d --build`.
3. Откройте `http://server:8084` и пройдите мастер настройки.

По умолчанию запускается собственный PostgreSQL. Для внешней базы задайте `BUNDLED_DB_REPLICAS=0`, запустите сервис и укажите подключение в мастере.

Docker Compose должен быть версии 2.20 или новее: используется необязательная зависимость от контейнера встроенной базы.

## Уже реализовано

- bootstrap-конфигурация с шифрованием реквизитов;
- мастер первого запуска;
- разбор Queue ID, Message-ID, клиента, SASL, отправителя и получателей;
- LMTP/SMTP-статусы, DSN, ответы сервера и задержки;
- связи `queued as` и bounce-уведомлений;
- PostgreSQL-схема и комбинированный поиск;
- просмотр полной цепочки Queue ID;
- безопасное копирование данных в новую PostgreSQL с переключением только после проверки;
- Docker Compose со встроенной или внешней БД.
